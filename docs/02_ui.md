
# Sassie UI Specification

## UIの目的

SassieのUIは、情報を効率よく消費するためのものではありません。

ユーザーが少し立ち止まり、余白を読むためのUIです。

一般的なSNSよりも、表示情報を少なくし、余白を広く取ります。

## デザイン方針

- 白を基調とする
- 黒とグレーを中心にする
- 色数を増やさない
- 派手なグラデーションを使わない
- 大きな影を使わない
- 太い境界線を使わない
- 角丸を過剰に使わない
- 情報を詰め込まない
- アニメーションはフェード中心
- 操作結果を派手に祝わない
- SNSらしい賑やかさを避ける

## カラートークン

```ts
export const colors = {
  background: "#FFFFFF",
  surface: "#FFFFFF",
  textPrimary: "#202020",
  textSecondary: "#6F6F6F",
  textMuted: "#9A9A9A",
  border: "#E8E8E8",
  borderStrong: "#D8D8D8",
  surfaceMuted: "#F7F7F7",
  selectedSurface: "#F2F2F2",
  selectedBorder: "#CFCFCF",
};
```

強いアクセントカラーはMVPでは使用しません。

## タイポグラフィ

- 日本語が自然に読めるシステムフォントを使用する
- 本文サイズは14px〜16pxを基本とする
- 見出しを過剰に大きくしない
- 行間を広めにする
- 太字を多用しない
- 英数字だけ別フォントにしない

推奨フォント：

```css
font-family:
  -apple-system,
  BlinkMacSystemFont,
  "Segoe UI",
  "Hiragino Kaku Gothic ProN",
  "Hiragino Sans",
  "Yu Gothic",
  Meiryo,
  sans-serif;
```

## 共通レイアウト

- モバイルファースト
- 最大コンテンツ幅は640px前後
- PCでは中央に配置
- 左右余白は最低16px
- 主要セクション間は24px以上
- カード内部余白は20px前後
- タップ領域は最低44pxを目安にする

## アイコン

余韻リアクションや操作アイコンには、Webで安定して表示できるSVGアイコンを使用します。

推奨：

- `lucide-react`
- またはプロジェクト内の共通SVGコンポーネント

絵文字を操作アイコンとして使用しないでください。

理由：

- OSやブラウザで見た目が変わる
- `?` や文字化けになる可能性がある
- 意味が強く固定されやすい

## 主要画面

### 1. Timeline

ルート：

```text
/
```

役割：

- 言葉にならなかった投稿を受け取る
- 痕跡を読む
- 余韻を置く
- 新しい言葉を書き始める

ヘッダー：

- 中央に `Sassie`
- 右側に控えめな作成導線
- 左側に意味のないメニューを置かない
- 通知ベルを置かない
- プロフィール画像を置かない

投稿カード表示例：

```text
□□□□□□□□□□□□

48文字
送信されませんでした

何度も言葉を選び直しました
最後の入力から26秒間、画面は静かでした

[月] 12  [カップ] 5  [芽] 3
```

カードに表示するもの：

- マスク文字列
- 元の文字数
- 「送信されませんでした」
- 痕跡文を最大3件
- 余韻リアクション
- 作成日時の控えめな表示

表示しないもの：

- 投稿本文
- 投稿者の顔写真
- フォロワー数
- ユーザーランク
- コメント数
- シェア数
- 閲覧数
- 拡散ボタン
- メニューアイコン

0リアクション時：

```text
余韻はまだありません
```

小さく、薄いグレーで表示します。

「反応がありません」
「誰も見ていません」
など、不安を生む表現は使用しません。

### 2. Compose

ルート：

```text
/compose
```

役割：

- 言葉を書く
- 入力の痕跡を記録する
- 本文を残さず手放す

表示するもの：

- 静かな説明文
- テキスト入力欄
- 現在の文字数
- 本文が保存されないことの説明
- 「手放す」ボタン

推奨文言：

```text
ここに書いた言葉は、誰にも表示されません。
残るのは、言葉を選んだ痕跡だけです。
```

ボタン文言：

```text
手放す
```

使用しない文言：

- 投稿する
- 公開する
- 共有する
- 配信する
- 送信する

入力中は本文を表示して構いません。

本文が表示されるのは、この画面の入力欄だけです。

手放した後：

1. 入力欄をフェードアウト
2. 本文をメモリから破棄
3. マスク文字列をフェードイン
4. 文字数を表示
5. 「送信されませんでした」を少し遅れて表示
6. タイムラインへ戻る

完了表示例：

```text
□□□□□□□□□□□□

48文字
送信されませんでした
```

紙吹雪、チェックマーク、大きな成功表示は使用しません。

### 3. Post Detail

ルート：

```text
/posts/[id]
```

役割：

- 投稿に残った痕跡をゆっくり読む
- 複数の余韻を置く

表示例：

```text
□□□□□□□□□□□□

48文字
送信されませんでした

この投稿に残っていた痕跡

何度も言葉を選び直しました
途中で一度、すべて消しました
最後の入力から26秒間、画面は静かでした

余韻

[月] 12
[カップ] 5
[芽] 3
[本] 2
[灯り] 1
```

「AIが見つけた痕跡」という文言は使用しません。

余韻は複数種類置けます。

同じ種類の余韻は、同じ端末から1回までです。

選択済みの余韻は、次の方法で控えめに表現します。

- 薄いグレー背景
- 少し濃いアイコン
- 薄い枠線

派手な色や大きなアニメーションは使用しません。

## 余韻リアクション

MVPでは次の5種類を使用します。

| ID | 表現 | アイコンの方向性 |
|---|---|---|
| moon | 静かな寄り添い | 月 |
| coffee | 一息つく時間 | カップ |
| sprout | 小さな前進 | 芽 |
| book | 読み受け取ったこと | 本 |
| candle | 静かな灯り | 灯り |

意味は説明しすぎないでください。

ユーザーが自由に受け取れる余白を残します。

## アニメーション

許可するもの：

- opacity
- 小さなtranslate
- 150ms〜400ms程度のフェード
- 控えめな選択状態の変化

避けるもの：

- バウンド
- 大きなスケール
- 紙吹雪
- 派手なスライド
- 振動的な動き
- SNS風のリアクションアニメーション

`prefers-reduced-motion`を尊重してください。

## レスポンシブ対応

### モバイル

- 1カラム
- 画面幅いっぱいに近いカード
- 左右16px程度
- 余韻は折り返し可能
- 入力欄は十分な高さを確保

### タブレット・PC

- 最大幅640px前後
- 中央配置
- 不要に横へ広げない
- 2カラム化しない
- モバイルと同じ静かな流れを維持

## アクセシビリティ

- アイコンボタンに`aria-label`を付ける
- 選択状態には`aria-pressed`を使う
- キーボード操作を可能にする
- 色だけで選択状態を表現しない
- コントラストを確保する
- フォーカスリングを消さない
- マスク文字列をスクリーンリーダーに大量読上げさせない

マスク表示には、必要に応じて次のようなラベルを付けます。

```text
48文字の言葉は送信されませんでした
```

## UI禁止事項

- Instagram風カード
- X風タイムライン
- LINE風吹き出し
- 赤い通知バッジ
- 大きなフローティングボタン
- プロフィール画像の羅列
- いいねハート
- シェア矢印
- コメント吹き出し
- 無限スクロールを煽る演出
- トレンド表示
- 人気順

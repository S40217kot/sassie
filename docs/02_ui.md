# UI Guidelines

The application is designed as a smartphone-first web app.

Desktop browsers display the app centered with large white margins.

Maximum content width:

420px–440px

---

## Screens

### Landing

Minimal.

Logo

Subtitle

One button.

---

### Timeline

A vertical list of traces.

Each card contains:

□□□□□□□□

35 characters

Message was not sent.

Several traces.

Reaction icons.

No profile images.

No usernames.

No timestamps.

---

### Create

Large textarea.

Large white space.

One Send button.

Nothing else.

---

### Detail

A single trace.

Scrolling reveals additional traces.

Information appears gradually.

---

## Visual Style

White background.

Very soft gray borders.

Large spacing.

Rounded corners.

Almost no shadows.

No gradients.

No colorful UI.

Typography is more important than decoration.

Negative space is part of the design.

# Sassie Design Manifesto

Sassie is quiet.

Do not compete for attention.

Do not optimize for engagement.

Do not reward users for posting.

Do not encourage addiction.

If a decision increases information,
it is probably the wrong decision.

If a decision removes unnecessary information,
it is probably the right decision.

White space is not empty.

Silence is not missing.

The user should feel calm.

The interface should never feel busy.

When unsure,

remove instead of adding.

When unsure,

make it quieter.

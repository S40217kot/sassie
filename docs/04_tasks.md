
# Sassie Development Tasks

## 現在の目標

Next.jsとVercelを使用して、SassieのWeb MVPを完成させる。

MVPのコア体験：

```text
書く
↓
手放す
↓
本文が消える
↓
□□□□と痕跡だけが残る
↓
受け取った人が余韻を置く
```

## MVP完成条件

以下がすべて成立した時点でMVP完成とします。

1. Webブラウザで動作する
2. スマホ幅で自然に操作できる
3. 文章を書ける
4. 入力の痕跡を取得できる
5. 手放すと本文が消える
6. 本文が保存されない
7. マスクと痕跡だけが残る
8. TimelineとDetailに本文が表示されない
9. 複数の余韻を置ける
10. 同じ余韻は1端末につき1回まで
11. Vercelで公開できる
12. Lint、型チェック、テスト、ビルドが通る
